# PERMANENT PLACE NUMBER RULE — MARK DECISION

Date: 2026-09-13
Status: BINDING

Mark requires every place/location to carry one permanent user-facing number everywhere.

Rules:
1. Every location/place gets exactly one permanent `A###` identifier.
2. The same identifier must appear every time that location is named in PDFs, day blocks, place lists, route tables, decision surfaces and Mark-facing summaries.
3. A location must never receive a different display number merely because the PDF/order/day changes.
4. New/recovered locations receive new permanent numbers; existing A001–A079 are never renumbered.
5. The next Mark-facing PDF must make the permanent place number visually prominent on every occurrence so Mark can refer to a place by number alone.
6. Day-block ordering and permanent place numbering are independent: moving a place to another day never changes its number.
7. Before the next PDF is generated, every currently unnumbered live/recovered place must be assigned a permanent A-number and the mapping mechanically checked for uniqueness.

`PERMANENT_PLACE_NUMBERING_REQUIRED = YES`
`RENUMBER_EXISTING_A001_A079 = NO`
`PDF_OCCURRENCE_MUST_ALWAYS_SHOW_ID = YES`
