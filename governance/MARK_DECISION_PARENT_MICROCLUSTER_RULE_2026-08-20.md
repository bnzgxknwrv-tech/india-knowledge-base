# MARK DECISION PARENT / MICROCLUSTER RULE

Date: 2026-08-20
Status: ACTIVE

## Core rule
During Mark A/B/C review, one physical parent site / compound / ashram / hermitage / station / temple complex / hospital campus / historic property gets ONE Mark decision number.

Known child rooms, shrines, courtyards, verandas, gates, cremation points, gardens, caves, platforms, photo positions and other micro-sites remain losslessly preserved beneath the parent as M1, M2, M3... They do NOT get separate Mark A/B/C decisions merely because the research database stores them separately.

## Separate decision number only when
A child is physically a separate destination requiring a materially separate visit, route, access decision, or meaningful travel detour.

## Decision effect
If parent = A, all known relevant child micro-sites are automatically included as visit-guide targets subject to access and authenticity. They remain individually documented for the final A-site guide.

If parent = B/C, child findings remain preserved and may later justify an upgrade, but Mark is not asked to score each child separately.

## Example
NKB Vrindavan Ashram = one A decision.
Under it: Mahasamadhi/cremation site, Maharajji office/room, courtyard, Hanuman sanctum, gate and any other known meaningful micro-sites = M1...Mn.

Fouzdar Kunj = one A decision.
Upper room + semicircular veranda = M1/M2.

Vrindavan Railway Station = one A decision.
Nearby unresolved Kriya-initiation micro-location = M1 under station visit rather than a second travel stop.

## Presentation requirement
Before presenting a cluster to Mark, collapse the decision surface to parent visit-units FIRST. Then describe all known micro-sites under each parent. Do not make Mark repeatedly score the same physical terrain.
