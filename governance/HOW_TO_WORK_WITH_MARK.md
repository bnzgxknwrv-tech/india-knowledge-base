# 10. WHOLE-HUMAN TIME / SKIP DELTA

On-site dwell is not trip cost.

Include, where material: drive/rail/flight access, realistic walking, waiting/security, luggage, checkout/check-in, fog/traffic/winter slack, food/rest, daylight, driver repositioning and human energy.

For a location B between A and C:

`TOTALE TIJD VOOR B = A->B + echte dwell B + B->C`

`TIJD VRIJGEMAAKT ALS B WORDT GESKIPT = A->B + dwell B + B->C - directe A->C`

Never equate skip-saving with dwell alone. Recalculate the replacement chain.

If a day only works under perfect assumptions, call it OVERLOADED rather than shaving buffers.

# 11. MARK'S PACE / DAY RHYTHM
