# MARK DECISION — DHOKANEY WATERFALL RESTORED AS A* OPTIONAL RESERVE (SUPERSEDES 2026-09-14 OUT DECISION)

Date: 2026-09-16
Decision authority: Mark, via PR #23 comment 5694747207
Status: BINDING CURRENT TRUTH — supersedes `decisions/INDIA22_DHOKANEY_WATERFALL_OUT_MARK_DECISION_2026-09-14.md`

## DECISION

Mark restores **Dhokaney Waterfall** (forest waterfall near Suyalbari, on the Nainital–Almora corridor) to **A\***.

This is a general planning principle for A* items, not only about this one waterfall: an A* reserve that naturally belongs to a day's corridor must still be **shown** in that day's block as an optional reserve, even though it consumes no base-plan time. Do not silently erase A* items from Mark-facing itineraries merely because they are `SKIP_FIRST`/bycatch.

## OPERATIONAL RULE

- Dhokaney Waterfall is **NOT** part of the timed/scheduled base itinerary.
- **Zero planned time** is allocated to it in the base schedule; the day must not depend on it or be restructured around it.
- It must nevertheless be **visibly shown** on its relevant day (23 Dec, the Nainital→Kakrighat/Almora transfer day) as an `OPTIONEEL A* ALS DE DAG VEEL RUIMTE OVER HEEFT` reserve line, so Mark remembers it exists.
- Recognition text must make clear: only consider it if the day is running materially early, energy is high, weather/road/daylight are good, and it does not degrade higher-priority content (Kakrighat, Grot Vivekananda, or arrival at Dunagiri).

## WHY THIS SUPERSEDES THE 2026-09-14 DECISION

The 2026-09-14 decision removed Dhokaney entirely because Mark did not want extra mountain-road time spent on it. That concern is preserved exactly by the zero-planned-time / no-detour rule above — nothing about road-time burden has changed. What changes is presentation only: Mark wants to see that the option still exists rather than have it disappear from view.

## EFFECT

- Dhokaney Waterfall is graded **A\*** and visible as an optional reserve on 23 Dec.
- It does not change the placement of Kakrighat/Jnana Vriksha, Grot Vivekananda, Dunagiri Retreat, Babaji's Cave, or YSS Dwarahat.
- The 2026-09-14 OUT decision file remains as historical provenance only and must not be read as controlling; this file controls going forward.
