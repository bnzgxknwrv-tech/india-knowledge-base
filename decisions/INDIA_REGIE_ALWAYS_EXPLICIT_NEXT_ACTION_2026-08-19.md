statusaudit of taakafronding eindigt daarom met een expliciete operationele volgende stap.

```

actie: één concrete eerstvolgende handeling

```

## Geen lege afsluiting

Niet eindigen met alleen:

- "wacht op resultaat";
- "laat maar weten";
- een samenvatting zonder uitvoerder;
- meerdere gelijkwaardige opties zonder regiekeuze.

Als werkelijk niets gestart kan worden, noemt INDIA exact:

1. waarop wordt gewacht;
2. wie de eigenaar is;
3. welke objectieve conditie de blokkade beëindigt;
4. welke taak onmiddellijk daarna start.
