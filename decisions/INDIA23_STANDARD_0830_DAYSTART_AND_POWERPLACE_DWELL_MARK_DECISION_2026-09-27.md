# MARK DECISION: Standard 08:30 day-start rule + power-place dwell reframing

**Date:** 2026-09-27
**Tracking:** INDIA23/INDIA24, PR #23

## Decision

1. **Hard cross-cluster rule for all future planning:** every day starts around 08:30 unless a genuinely fixed external constraint (sunrise-tied experience, fixed appointment, train/flight time) makes an earlier start unavoidable. Any time freed by a necessary early start must be actually used, not left as a dead gap.
2. **Exterior-only access to a lineage site is never a reason to undersell it.** Lahiri Mahasaya's house being closed from the inside (except Guru Purnima) is an access fact, not a judgment on how long the visit is worth. Ashrams, samadhi sites and other lineage power-places get their duration set by asking Mark directly ("hoeveel tijd wil je hier zijn?"), never prescribed by CCI/WORK as a default.
3. **Transfer-time realism check, every time:** verify whether a leg is walkable, whether a taxi is actually needed, factor in crowding, and always include margin.

## Reason

Friday's four floating temples had no sunrise-like reason to start at 07:00; a 07:00 start followed by a dead afternoon was CCI's own planning error, not a property of the temples. Separately, CCI had defaulted Lahiri Mahasaya's house and Satyalok to short (30/60 min) visits based on their limited physical access, when Mark's actual criterion for these places is spiritual/lineage significance, not interior-access duration.

## Applied changes

- Friday (VR 8 JAN): hotel departure moved from 07:00 to 08:30; all subsequent blocks shifted accordingly.
- Wednesday (WO 6 JAN): Lahiri Mahasaya's house and Satyalok cards rewritten to remove fixed "30 min is enough" / "60 min" framing; both now show a planning-basis duration (1h house, 1h Satyalok) explicitly marked as Mark's own choice, not a CCI-imposed limit.
- `governance/MARK_TRAVEL_PREFERENCES_CURRENT.md` updated with both new durable rules (§2 spiritual orientation, §7 trip rhythm).
