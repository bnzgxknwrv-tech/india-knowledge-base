## Purpose
Do not grade Varanasi old A sites from isolated distances. The city has several fixed A+ anchors that naturally form walking/rickshaw corridors. Candidates inside those corridors are low-friction catches and should not be treated as separate day trips.

- VARANASI / BHADAINI / Shree Shree Ma Anandamayi Ashram (bezoekbaar ashram van Anandamayi Ma) — A+.

## Corridor V1 — SOUTH VARANASI WALK/RICKSHAW WORLD
Core: `ASSI A+ -> ANANDAMAYI A+ -> south-city temples -> KRIYA/ghat spine`.

Easy/low-friction old A catches by protected-coordinate geometry:
- VARANASI / TULSI GHAT / Tulsi Ghat + Lolark Kund (Tulsidas-ghat + oude rituele zon/vruchtbaarheidsbron) — A; ~0.10 km straight-line from Anandamayi A+ for Tulsi Ghat component; obvious local catch.
- VARANASI / DURGA KUND-AREA / Tulsi Manas Temple (tempel rond Tulsidas/Ramcharitmanas-traditie) — A; ~0.58 km straight-line from Assi A+.
- VARANASI / DURGA KUND / Durga Temple + Durga Kund (rode godinnentempel met heilige vijver) — A; ~0.64 km straight-line from Assi A+.
- VARANASI / ANAND BAGH / Bhaskarananda Samadhi (samadhi/herdenkingsplek van yogi Bhaskarananda) — A; ~0.96 km straight-line from Assi A+; approximate coordinate quality, but city-scale local.
- VARANASI / SANKAT MOCHAN / Sankat Mochan Hanuman Temple (levende Hanuman-tempel verbonden met Tulsidas) — A; ~1.02 km straight-line from Assi A+.

Disposition: none is a separate day. These should be judged mainly on content/interest, because logistics are favorable.

## Corridor V2 — CENTRAL / OLD-CITY GHAT WALK
Core: `KRIYA CORE A+ -> DASHASHWAMEDH A+ -> KASHI VISHWANATH A+ -> MANIKARNIKA A+ -> PANCHGANGA A+`.

Easy old A catch:
- VARANASI / LALITA GHAT / Lalita Ghat + Nepali/Kathwala Temple (Ganges-ghat met Nepalese pagodetempel) — A; ~0.12 km straight-line from Manikarnika A+ and ~0.25 km class from Kashi Vishwanath A+. This is effectively on the A+ old-city walking spine.

Small city detour:
- VARANASI / KABIR CHAURA / Kabir Chaura Math (centrum van Kabir-traditie) — A; ~1.47 km straight-line from Panchganga A+. Likely short rickshaw/auto/local diversion rather than a separate excursion. Requires practical traffic/access routing later, but not a hard cut.
