## PURPOSE
Ordinary A/B/C cannot be judged responsibly before the intrinsically non-negotiable anchors are identified and the practical proximity of all other candidates to those anchors is known.
Only Mark assigns A+, A, B or C.

## HARD DISPLAY RULE
Every non-obvious Indian place/site/institution/festival/local term shown to Mark immediately gets a short plain-Dutch explanation in parentheses, every time it is mentioned. Never rely on remembered names.
Never display `Nirmal Dham` alone; use `Nirmal Dham (rustplaats/Mahasamadhi van Shri Mataji Nirmala Devi)`.

## TERMINOLOGY — HARD
Use **cost/kosten** only for money. For planning use duration, extra travel time, detour, walking/driving time and logistical burden. Never use `gratis` for small time impact.

## TWO LEVELS
### A+ CLUSTER / FIXED TRAVEL WORLD
Definitely part of the trip. Current fixed core:

### A+ LOCATION / EXPERIENCE
A place/experience intrinsically among the real reasons for the India journey, independent of convenience.
Explicit examples already given by Mark: Babaji's Cave, Lahiri Mahasaya's house, Bodhi Tree, Nirmal Dham (rustplaats/Mahasamadhi van Shri Mataji Nirmala Devi) and Taj Mahal.

## HARD TRAVEL QUALITY RULE
Fixed core clusters are already retained; the task is to determine how much time they truly require when done properly. Do not compress them merely to preserve later clusters.

## DECISION ORDER — HARD
1. Discovery is complete enough: person/AOAY + regional + traveler/LP + world-magnet universes exist.
2. Fixed core cluster set is locked for this costing phase.
3. **FIRST A+ PASS:** Mark confirms/rejects INDIA's concise proposal of the obvious intrinsic A+ anchors.
4. **OLD-A PROMOTION PASS:** before traveler/LP grading, INDIA presents EVERY preserved existing A-location in the fixed clusters that is not already A+, with descriptive labels and relevance. Mark decides whether any additional old A should be promoted to A+.
5. The A+ set is now complete enough for geometry. INDIA resolves physical identity/coordinate confidence for all selected A+ anchors first.
6. INDIA overlays every remaining old A/B/C, new regional candidate and traveler/Lonely-Planet finding against the nearest/relevant A+ and computes:
   - trustworthy identity/coordinates where possible;
   - straight-line distance only as descriptive support;
   - real walking/driving/boat travel time;
   - incremental extra travel time / omweg from A+ path or sleep base;
   - same compound / walkable / natural bundle / separate excursion;
   - isolation if far from all A+ and other retained items.
7. Only with that context does Mark re-rate ordinary A/B/C.
   Explicit Mark logic: an otherwise-A place requiring roughly three hours separate travel may become B because it consumes a day; a similar-strength place about 15 minutes from an A+ may remain/become A.
8. INDIA builds a realistic COMPLETE-EXECUTION schedule for that fixed cluster using retained A/B plus transfer/buffer reality.
9. Derive true minimum duration/nights.
10. Repeat through all fixed core clusters.
11. Only after fixed core time footprint is known, evaluate route-sensitive/reserve clusters against remaining trip space.
12. Global route / quarter-hour itinerary comes last.

## PROXIMITY METRIC
Reuse `PROXIMITY_1KM_3KM_MATRIX.csv` but do not use kilometres alone. Required fields where feasible:
- `nearest_A_plus`
- `distance_km`
- `travel_mode`
- `realistic_travel_time_one_way`
- `incremental_detour_time`
- `walkable_from_A_plus`
- `same_compound_or_parent`
- `natural_bundle`
- `isolated_from_all_A_plus`
- `coordinate_confidence`

Straight-line distance never substitutes for route reality in mountains, across rivers, restricted zones or poor-road areas.
