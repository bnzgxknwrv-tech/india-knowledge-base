## CURRENT MARK-DECISION INTERPRETATION
A+ promotion should now be based on intrinsic importance, with logistics shown so Mark can see whether a separate A would materially consume time. Close, naturally bundled A sites need not become A+ merely to ensure they are visited; their later A status can retain them cheaply. Far A sites such as Jageshwar or the Crank's Ridge module require explicit awareness because they can consume substantial cluster time.
