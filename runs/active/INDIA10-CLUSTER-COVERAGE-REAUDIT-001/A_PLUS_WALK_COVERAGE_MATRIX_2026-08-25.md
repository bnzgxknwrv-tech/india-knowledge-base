## PURPOSE
Hard project goal: for every current A+ world, actively test whether there is a genuinely beautiful, meaningful, safe walk at/from/through the site. Do not force mediocre walks merely to fill a cell.

Coverage states:
- WALK_LOCKED = walk is already selected/strongly operationally closed.
- WALK_CANDIDATE = strong route exists but exact Komoot/legal/safety/geometry closure or Mark decision remains.
- WALK_GAP = no sufficiently good walk identified yet; targeted discovery required.
- WALK_NOT_NEEDED = only if a walk would add no real value; never use merely to avoid searching.

Safety is a veto layer. Komoot route existence is not legal/safety proof.
