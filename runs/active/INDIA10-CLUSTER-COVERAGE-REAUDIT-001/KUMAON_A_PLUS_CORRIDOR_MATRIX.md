# INDIA10 — KUMAON A+ CORRIDOR MATRIX

status: ACTIVE_CURRENT_GEOMETRY_CONTEXT
updated: 2026-08-24

## PURPOSE
Mark cannot responsibly rate old A sites from isolated point-to-point distances. For Kumaon, every old A must be evaluated against the actual corridors connecting the fixed A+ spine. A site can be highly attractive when it is a natural taxi/transfer catch even if it would not justify a dedicated sleep module.

User-facing naming remains `CLUSTER / PLAATS / PLEK (uitleg) — huidige status`.

- KUMAON / HAIDAKHAN / Historische Haidakhan-grot (grot uit aparte Haidakhan Babaji-traditie) — A+.
- KUMAON / NAINITAL / Hotel Evelyn (historisch hotel waar Ram Dass verbleef) — A+.

## GEOGRAPHIC CORRIDOR SKELETON — NOT YET FINAL DAY ORDER
Most efficient-looking spine to test first:
`HAIDAKHAN -> NAINITAL/HOTEL EVELYN -> KAINCHI -> KHAIRNA -> RANIKHET -> DWARAHAT -> KUKUCHINA/DUNAGIRI`.
This is a geometry skeleton, not a locked itinerary.

### C1 HAIDAKHAN -> NAINITAL
Current public route sources put this roughly in the ~50–65 km road class and ~1h20–2h30 depending exact Haidakhan approach/road source. Exact trip-day time must be live-routed later.
CRITICAL: Kasar Devi / Crank's Ridge / Almora is NOT a natural pass-through on this corridor. Do not sell Turiya/Bodh as a Haidakhan->Nainital easy catch.

### C2 NAINITAL -> KAINCHI
Official Kumaon source: Kainchi is ~17 km from Nainital; current realistic taxi sources are roughly 40–60 min depending traffic.
This is a direct fixed-A+ corridor. No Almora/Crank's side site is naturally on it.

### C3 KAINCHI -> KUKUCHINA/DUNAGIRI — DIRECT SPINE
Direct practical spine documented by pilgrim/travel sources:
`KAINCHI -> KHAIRNA -> RANIKHET -> DWARAHAT -> KUKUCHINA`.
Current eUttaranchal distance chart: Kainchi -> Dwarahat ~71.7 km / ~2h24; Dwarahat -> Kukuchina is commonly ~20 km in Babaji-cave itineraries. Winter/fog/traffic buffer required.

#### EASY TRANSFER CATCH: KAKRIGHAT
KUMAON / KAKRIGHAT / Kakrighat (Kosi-rivierplek waar Vivekananda in 1890 zijn microkosmos/macrokosmos-realisatie had; ook NKB-ashramlaag) — current A.
- Kakrighat is ~20–22 km beyond Kainchi on the Almora road.
- Khairna is the junction where the direct Ranikhet road branches; Kakrighat is ~7 km beyond Khairna toward Almora.
- Therefore on DIRECT C3, Kakrighat is approximately a ~14 km out-and-back road detour from the Khairna junction, not a new destination/day.
- Working planning class: about 20–30 min extra driving + desired visit time; likely ~45–90 min total increment depending stop duration.
- DISPOSITION: MEGA-RELEVANT TRANSFER CATCH. Must be shown to Mark as such, not as a dropped Almora-module site.

## C3-ALT KAINCHI -> KUKUCHINA VIA ALMORA / KASAR DEVI
Alternative corridor deliberately trades transfer efficiency for catching several old A sites:
`KAINCHI -> KAKRIGHAT -> ALMORA -> KASAR DEVI/CRANK'S RIDGE -> onward to DWARAHAT -> KUKUCHINA`.

Baseline comparison from current route sources:
- Direct Kainchi -> Dwarahat: ~71.7 km / ~2h24.
- Kainchi -> Almora: ~45.3 km / ~1h19.
- Almora -> Dwarahat: ~73.2 km / ~2h30.
- Therefore merely routing through Almora is about ~118.5 km / ~3h49 versus ~71.7 km / ~2h24 direct: roughly +47 km and +1h25 raw driving before local Kasar/visit time.
- Kasar Devi is ~8 km from Almora, roughly 15–30 min each way; if an out-and-back is needed, local Kasar access adds around ~16 km / ~30–60 min road class.
- Working total difference versus direct spine: roughly +1h45 to +2h30 driving, BEFORE time spent at Turiya/Bodh/Ramakrishna/Chitai.
- This can still be a transfer-day conversion rather than an extra sleep/night if visits are bounded and access aligns.

### RIDGE/ALMORA CATCHES IF C3-ALT IS CHOSEN
KUMAON / CRANK'S RIDGE-KASAR DEVI / Turiya Niwas (historische kluizenaarswoning van Alfred 'Sunyata' Sorensen) — current A.
- Near Kasar Devi; current accommodation listing places it ~10 min walk from Kasar Devi Temple.
- If C3-ALT chosen, this is a local catch, not a separate mountain day.

KUMAON / CRANK'S RIDGE-KASAR DEVI / Bodh Ashram (Evans-Wentz/Lama Govinda/Tibetaans-boeddhistische zoekersplek) — current A.
- Same Kasar/Crank's Ridge module as Turiya.
- If C3-ALT chosen, evaluate together with Turiya; never treat as separate day.

KUMAON / ALMORA / Ramakrishna Kutir (levend Ramakrishna Mission-retraitecentrum; geen verblijfplaats van Sri Ramakrishna zelf) — current A.
- Local Almora catch if C3-ALT chosen; otherwise not on direct corridor.

KUMAON / CHITAI / Chitai Golu Devta Temple (Kumaoni 'god van gerechtigheid'-tempel met duizenden bellen en verzoekschriften) — current A.
- District Almora places Chitai about 8 km from Almora.
- Small local add-on to C3-ALT; otherwise not on direct C3.

### NOT AN EASY CATCH: JAGESHWAR
KUMAON / JAGESHWAR / Jageshwar Dham + Dandeshwar (grote vroegmiddeleeuwse Shiva-tempelgroepen in deodarwoud) — current A.
- Kainchi -> Jageshwar ~83 km / ~2h39 current chart.
- Almora -> Jageshwar ~41 km / ~1h30 one way.
- Even if C3-ALT uses Almora, Jageshwar remains a substantial branch; roughly ~3h extra return driving if returning to Almora, or still a large diversion if continuing to Dwarahat.
- DISPOSITION: NOT a simple taxi catch. Only retain if its own importance justifies real time pressure.

## CURRENT CORRIDOR CONCLUSIONS
1. Crank's Ridge is NOT naturally between Haidakhan and Nainital.
2. The critical opportunity corridor is Kainchi -> Babaji/Kukuchina.
3. Kakrighat is the clearest easy old-A transfer catch on the direct route.
4. Turiya + Bodh + Ramakrishna Kutir + Chitai become plausible only if Mark deliberately chooses the longer Almora/Kasar transfer variant; then they can be bundled without a dedicated sleep module.
5. Jageshwar remains a real side excursion even under the Almora variant.
6. Therefore `ROUTE-DEFERRED` does NOT mean `ignore`; it means `test as corridor capture before regrading`.

## HARD RULE GOING FORWARD
Before any A/B/C/A+ re-rating in a fixed cluster, show not only nearest A+ but also whether the site lies:
- ON a mandatory A+ corridor;
- within a SMALL TRANSFER DETOUR;
- within an ALTERNATIVE CORRIDOR that can capture several sites;
- or as a TRUE SIDE EXCURSION.
Mark should never be asked to decide without this corridor context.
