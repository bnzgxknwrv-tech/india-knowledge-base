## PURPOSE
Every old A/B/C is evaluated against actual corridors connecting the fixed A+ spine. A site can be highly attractive when it is a natural taxi/transfer catch even if it would not justify a dedicated sleep module.

## GEOGRAPHIC CORRIDOR SKELETON — NOT FINAL DAY ORDER
Most efficient-looking spine to test first:
`HAIDAKHAN -> NAINITAL/HOTEL EVELYN -> KAINCHI -> KHAIRNA -> RANIKHET -> DWARAHAT -> KUKUCHINA/DUNAGIRI`.

### C1 HAIDAKHAN -> NAINITAL
Working public route class: roughly ~50–65 km and ~1h20–2h30 depending exact Haidakhan approach/road source. Exact trip-day time must be live-routed later.
Kasar Devi / Crank's Ridge / Almora is NOT a natural pass-through on this corridor.

### C2 NAINITAL -> KAINCHI
Kainchi is ~17 km from Nainital; current realistic taxi class roughly 40–60 min depending traffic.
No Almora/Crank's side site is naturally on this direct fixed-A+ corridor.

### C3 KAINCHI -> KUKUCHINA/DUNAGIRI — DIRECT SPINE
Direct practical spine:
`KAINCHI -> KHAIRNA -> RANIKHET -> DWARAHAT -> KUKUCHINA`.
Working current route class: Kainchi -> Dwarahat ~71.7 km / ~2h24; Dwarahat -> Kukuchina commonly ~20 km in Babaji-cave itineraries. Winter/fog/traffic buffer required.

#### KEEP — EASY TRANSFER CATCH
KUMAON / KAKRIGHAT / Kakrighat (Kosi-rivierplek waar Vivekananda in 1890 zijn microkosmos/macrokosmos-realisatie had) — huidige status: A.
- Kakrighat is ~20–22 km beyond Kainchi on the Almora road.
- Khairna is the junction where direct Ranikhet road branches; Kakrighat is ~7 km beyond Khairna toward Almora.
- On direct C3 this is roughly a ~14 km out-and-back detour from the Khairna junction, not a new destination/day.
- Working class: ~20–30 min extra driving + visit time; likely ~45–90 min total increment depending stop duration.
- Mark decision 2026-08-24: KEEP A precisely because corridor analysis turns it into an easy catch.

## C3-ALT KAINCHI -> KUKUCHINA VIA ALMORA / KASAR DEVI
Alternative corridor:
`KAINCHI -> KAKRIGHAT -> ALMORA -> KASAR DEVI/CRANK'S RIDGE -> DWARAHAT -> KUKUCHINA`.

Baseline comparison:
- direct Kainchi -> Dwarahat: ~71.7 km / ~2h24;
- Kainchi -> Almora: ~45.3 km / ~1h19;
- Almora -> Dwarahat: ~73.2 km / ~2h30;
- via Almora baseline ~118.5 km / ~3h49 versus ~71.7 km / ~2h24 direct: roughly +47 km / +1h25 raw driving before Kasar/local visits;
- Kasar local access can add roughly another ~30–60 min road class;
- working total difference versus direct: about +1h45 to +2h30 driving BEFORE visit time.

### TRUE SIDE EXCURSION — CUT
KUMAON / JAGESHWAR / Jageshwar Dham + Dandeshwar (grote vroegmiddeleeuwse Shiva-tempelgroepen in deodarwoud) — huidige status: C.
- Kainchi -> Jageshwar ~83 km / ~2h39 current chart.
- Almora -> Jageshwar ~41 km / ~1h30 one way.
- Even if the Almora variant were used, Jageshwar remains a substantial branch.
- Mark decision 2026-08-24: C / hard practical cut for current trip.

## CURRENT CORRIDOR CONCLUSIONS
1. Crank's Ridge is NOT naturally between Haidakhan and Nainital.
2. The critical corridor is Kainchi -> Babaji/Kukuchina.
3. Kakrighat is the clear retained easy transfer catch and stays A.
4. Turiya, Bodh Ashram, Ramakrishna Kutir and Chitai are now C; do not choose a longer Almora transfer to rescue them.
5. Jageshwar is C and remains a true side excursion.
6. The default efficient C3 corridor therefore wins unless future new A+/traveler evidence materially changes the route.
