## TOPOLOGY OPTIONS

### OPTION N1 — DELHI -> KUMAON -> DELHI -> AGRA; RISHIKESH OMITTED
Pros:
- simplest conceptual spine;
- possible air/train exit from Kumaon via Pantnagar/Kathgodam.
Cons:
- returning to Delhi after Kumaon can consume most/all of a day anyway;
- if Delhi core has already been completed before Kumaon, the return may be pure transit rather than content.
Status: VALID BASELINE, not automatically best.

### OPTION N2 — DELHI -> KUMAON -> RISHIKESH/HARIDWAR -> AGRA
Pros:
- no forced return to Delhi after Kumaon if Delhi A+ world is completed first;
- Rishikesh/Haridwar acts as a west/south-west bridge out of Kumaon before continuing to Agra;
- both legs are long but comparable to the long Kumaon->Delhi / Kumaon->Agra exit problem that exists anyway;
- Haridwar and Rishikesh are close enough to share one regional base/world.
Cons:
- Kumaon->Rishikesh is a real travel-day edge, not a casual transfer;
- Rishikesh/Haridwar adds its own desired stay-days on top of travel burden;
- winter mountain-road timing and fatigue must be respected.
Status: `STRUCTURALLY_PLAUSIBLE / SERIOUS_GLOBAL_CANDIDATE`.

### OPTION N3 — DELHI -> RISHIKESH/HARIDWAR -> KUMAON -> DELHI/AGRA
This risks creating a west->east mountain movement followed by another long south/west exit and potentially a Delhi return.
Status: `LIKELY_INFERIOR / DO_NOT DEFAULT` unless later flight/date/event constraints prove otherwise.

## PROVISIONAL CONCLUSION
RISHIKESH/HARIDWAR/KANKHAL should NOT be cut merely because travel times are now counted.

Best current hypothesis:
`DELHI -> KUMAON -> RISHIKESH/HARIDWAR -> AGRA`

This makes Rishikesh/Haridwar an `ALTERNATIVE_CORRIDOR_BUNDLE` candidate rather than a `TRUE_SIDE_EXCURSION`.

The incremental route burden is likely much smaller than 'add an entire out-and-back from Delhi', because the trip already needs a long exit from eastern Kumaon toward the plains. The true extra cost of retaining Rishikesh/Haridwar is therefore primarily:
1. the number of nights / full visit days Mark wants there;
2. any incremental road time versus the best direct Kumaon->Agra or Kumaon->Delhi->Agra exit;
3. any special-date constraint (e.g. 31 Dec) that forces premature departure from Kumaon or causes waiting/backtracking.
