# KASAR DEVI / ALMORA -> RISHIKESH ROUTE DECISION DELTA

Date: 2026-08-23
Owner of route preference: Mark

## DECISION
Kasar Devi / Almora no longer receives automatic dedicated sleep-module priority in the 34-day route. It yields route capacity to Rishikesh / Haridwar / Kankhal.

Reasoning:
- Jageshwar was A mainly because the route was already expected to be in that wider area, not because it independently outranks the major retained clusters.
- Kasar Devi / Crank's Ridge / Turiya Niwas remain historically meaningful and all existing site-level A/B/C evidence is preserved; no old site lock is deleted.
- Kakrighat may remain a transfer stop if the actual route naturally passes it; it does not justify an Almora sleep base.
- Rishikesh itself has independent personal pull for Mark, while the same wider module also contains Kankhal Anandamayi Mahasamadhi (site A), Har Ki Pauri Ganga Aarti (light A), Beatles Ashram (light A), and rafting (B).
- 'Light A' means visit if the cluster is included; it does not independently rescue/open a cluster.

## ROUTE IMPLICATION
For first real itinerary modelling:
- keep Haidakhan as separate experiential stay;
- keep Nainital / Hotel Evelyn;
- keep Kukuchina / Joshi Guest House / Babaji Cave spine;
- do NOT reserve 3 nights by default for Kasar Devi / Almora / Turiya Niwas;
- assign freed capacity to a Rishikesh/Haridwar/Kankhal trial module and compare whole-trip fit.

## PRESERVATION
This is a CLUSTER / SLEEP-MODULE priority change only. It does NOT erase historical site-level A decisions from legacy canon. If later route geometry makes Kasar/Almora nearly free, those sites may still be reconsidered as ride-alongs, but no dedicated nights should be assumed.
